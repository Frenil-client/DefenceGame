## 0. 이 문서의 역할

데이터가 지켜야 할 규칙을 정의한다. 실제 수치는 data/*.csv에 들어가고 불변식은 tools/linter가 자동 검증한다.

**여기 적힌 모든 수치는 초기값이며 근거가 없다.** 시뮬레이터로 검증하기 전까지 어떤 숫자도 신뢰하지 않는다.

## 1. 축 정의

### 1-1. 속성 (5종)

| 속성 | 성격 |
|---|---|
| 화염 | 지속 피해 부여 |
| 냉기 | 이동 속도 감소 |

| 물리 | 안정적 단일 피해 |
| 신성 | 방어 감소 및 아군 강화 |

### 1-2. 역할 (5종)

| 역할 | 성격 | 주 용도 |
|---|---|---|
| 단일 | 단일 대상 고피해 | 보스 |
| 라인 | 사거리 내 다수 동시 타격 | **누적 처리** |
| 관통 | 방어력 무시 비율 보유 | 고방어 적 |
| 지속 | 시간당 피해, 방어 무시 | 순회 중 누적 소모 |
| 보조 | 방깎, 슬로우, 아군 강화 | 시너지 |

**라인 역할이 이 게임의 생명선이다.** 실패 조건이 필드 누적이므로 다수 동시 타격 수단이 없으면 반드시 막힌다.

### 1-3. 배치

**타일 종류 구분이 없다.** 루프 내부 배치 타일 어디든 놓을 수 있다. 배치의 유일한 변수는 사거리로 루프를 얼마나 커버하느냐이다.

## 5. 덱 사전 구성

- 런 시작 전 흔함 10종 중 6종 선택. 뽑기는 이 안에서만 나온다
- 덱 슬롯 기본 6칸, 메타 해금으로 7칸
- 초기 해금 6종, 나머지 4종은 플레이를 통해 해금
- 조합 불가 덱도 막지 않는다

덱 구성 화면 실시간 표시:

- 도달 가능한 레어, 유니크, 히든 종수
- 관통 및 방깎 보유 여부
- **라인 역할 보유 여부** (누적 처리 가능성 경고)

흔함 10종에서 6종을 고르는 경우의 수는 210가지. 히어로 5명과 곱하면 런 시작 조건이 1,050가지다.

## 7. 히어로

### 7-1. 기본 규칙

- 런 시작 시 5명 중 1명 선택. 배치 코스트 0
- **플레이어가 조작하지 않는다. 배치 위치만 정한다**
- 직접 전투에 참여한다 (자동 공격)
- **동시에 반경 auraRadius 안의 아군 유닛에게 오라 버프를 준다**
- 순회 몬스터는 아군을 공격하지 않으므로 히어로도 죽지 않는다
- 유닛을 합성할 때마다 경험치를 얻는다. 적 처치로는 얻지 않는다

### 7-2. 히어로 배치가 코어 결정인 이유

배치의 최적해는 두 가지를 동시에 만족해야 한다.

- **커버 효율**: 히어로 자신의 사거리가 루프를 많이 덮는 자리 (코너 안쪽)
- **오라 밀집도**: 아군 유닛이 많이 모여 있는 자리

이 둘이 일치하지 않는 경우가 많고, 맵이 매 런 다르므로 정답도 매번 다르다. 이것이 이 게임의 유일한 공간 퍼즐이다.

### 7-3. 히어로 5명

| ID | 이름 | 자체 역할 | 오라 효과 | 시작 특전 |
|---|---|---|---|---|
| HR01 | 성벽 | 라인 | 반경 내 아군 공격력 증가 | 오라 반경 확장 |
| HR02 | 포격수 | 단일 | 반경 내 아군 사거리 증가 | 자체 사거리 확장 |
| HR03 | 술사 | 라인 | 반경 내 아군 공격속도 증가 | 라인 반경 확장 |
| HR04 | 사제 | 보조 | 반경 내 아군 관통 부여 | 방깎 오라 추가 |
| HR05 | 각인자 | 지속 | 반경 내 아군 합성 코스트 감소 | 합성 경험치 증가 |

HR02의 사거리 오라와 HR03의 공속 오라는 성격이 크게 다르다. 사거리 오라는 커버 효율을 직접 올리므로 넓게 퍼진 배치에 유리하고, 공속 오라는 밀집 배치에 유리하다. **오라 종류가 배치 전략 자체를 바꾸도록 설계한다.**

HR05는 전투 기여가 가장 낮은 대신 합성 속도를 올린다. 성장 특화 히어로다.

### 7-4. 경험치

합성 시에만 획득한다.

| 합성 단계 | 획득 |
|---|---|
| 흔함 -> 레어 | 10 |
| 레어 -> 유니크 | 25 |
| 유니크 -> 히든 | 60 |

| 레벨 | 필요 누적 |
|---|---|
| 2 | 50 |
| 3 | 130 |
| 4 | 250 |
| 5 | 420 |
| 6 | 650 |
| 7 | 950 |
| 8 | 1350 |

최대 레벨 8. 스킬 카드 최대 7장.

### 7-5. 스킬 카드

- 히어로마다 고유 풀 16장
- 구성: **전투형 6장, 오라형 5장, 지원형 5장**
- 레벨업 시 풀에서 3장을 뽑아 1장 선택. 보유한 카드는 다시 나오지 않는다
- 전투형: 히어로 자체 화력. 이 중 최소 2장은 **라인딜 계열**이어야 한다 (누적 정리)
- 오라형: 반경 확장, 효과 강화, 효과 추가
- 지원형: 합성 코스트 감소, 경험치 증가, 뽑기 추가

### 7-6. 진화

- 히어로마다 진화쌍 3개
- 지정된 카드 2장을 모두 보유하면 자동 승격
- 진화 스킬이 런의 시각적 클라이맥스를 담당한다
- 진화쌍은 같은 히어로 풀 안에서만 성립한다

## 9. 웨이브와 누적

### 9-1. 웨이브

- 30웨이브. 웨이브당 30-45초
- 웨이브 시작 시 각 스폰에서 몬스터가 유입된다
- 유입량과 스탯은 웨이브 번호의 함수로 상승한다
- 이전 웨이브 몬스터가 남아 있어도 다음 웨이브는 예정대로 온다

### 9-2. 누적

- 필드에 살아 있는 몬스터 수가 **60**에 도달하면 패배
- 순회 몬스터는 아군을 공격하지 않는다. 일방적 처리 대상이다
- 누적 게이지가 화면 상단의 유일한 위기 지표다

**동시 표시 60기가 성능 상한 기준이다.** 상한값을 올리려면 렌더링 예산을 먼저 확인해야 한다.

### 9-3. 보스

| 보스 | 웨이브 | 특성 | 요구 |
|---|---|---|---|
| 강철 성채 | 10 | 고방어, 저속 | 관통 또는 방깎 |
| 창공의 눈 | 20 | 고속 이동, 주기적 소환 | 라인딜 + 슬로우 |
| 잠든 왕 | 30 | 고체력, 대량 소환 | 단일 + 라인 동시 |

보스도 루프를 순회한다. 별도 경로나 각성 연출이 없다. 그냥 강한 몬스터가 루프에 투입된다.

**보스 2가 소환을 하므로 누적 관리가 직접 시험된다.** 라인딜 수단이 없으면 여기서 막힌다.

### 9-4. 난이도 승급

|---|---|
| 1 | 몬스터 HP 15% 증가 |
| 2 | 웨이브 간격 10% 감소 |
| 3 | 누적 상한 60 -> 45 |
| 4 | 보스 소환량 2배 |
| 5 | 덱 슬롯 6 -> 5, G2와 G3 보장 해제 |

## 15. 확정되지 않은 것

- 유닛별 hp, atk, atkSpeed, range 실제 수치
- 히어로 5명의 기본 스탯, auraRadius, auraValue
- 스킬 카드 80장의 구체적 효과와 수치
- 웨이브별 유입량과 스케일링 곡선
- 보스 HP와 방어력
- 유물 80-100종의 구체적 규칙
- 커버 효율 지수의 목표 범위 (MAP_SPEC.md 5장)
- 무한 모드 지수 스케일링 계수

구조를 먼저 고정하고, 임시 수치로 시뮬레이터를 돌린 뒤, SIM-01 부터 SIM-11을 통과할 때까지 수치만 조정한다. **구조를 고치는 것과 수치를 고치는 것을 섞지 않는다.**
