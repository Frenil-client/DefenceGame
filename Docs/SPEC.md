# SPEC.md

SYNTHESIS (가칭) - 게임 사양

배치 위치: Docs/SPEC.md / 버전 0.4

버전 0.4 변경 (히어로즈 랜덤 디펜스 역기획):
- 조합 체계를 히랜디 실제 규칙에 맞춰 전면 재작성 (2기 결합에서 2-4기 혼합 등급 조합으로)
- 유닛 이동 규칙 신설. 그리드 지정 배치 + 연속 좌표 자유 이동 + 겹침 방지
- 맵 구성 상세와 조작 사양을 본문에 편입
- 계열(직업군) 축 도입, 속성/역할 축 폐기
- 도플갱어(와일드카드) 도입
- 패배 조건을 보스 제한시간 미처리로 변경 (필드 누적 상한 폐기)
- 마법 시스템 도입. 히어로 보류로 비는 능동 행동을 여기서 채운다
- 벽 형식 유닛 제외 확정
- 히어로 시스템 전체를 보류 (별도 문서로 분리, 이 문서에서는 다루지 않는다)
- 플레이 영상 확인 후 정정: 이동은 명령 기반, 창고 기능 추가, 보유 유닛 상한 미도입, 몬스터 겹침 허용, 특수 재화 미도입

## 0. 이 문서의 성격

**히어로즈 랜덤 디펜스(허니잼 게임즈, 2016)의 규칙을 역기획한 것이다.** 검증된 장르 문법을 그대로 재현하는 것이 1차 목표이고, 차별화는 코어가 재미있다는 것이 확인된 뒤에 얹는다.

원본과 우리의 근본 차이는 하나다.

| | 히랜디 | 우리 |
|---|---|---|
| 진행 구조 | 스테이지 클리어형 (8챕터 20여 스테이지) | 로그라이트 (매 런이 처음부터) |
| 성장 | 계정 단위 영구 성장 (영혼석, 유물, 특성) | 런 내 성장만. 메타는 해금 위주 |
| 맵 | 스테이지별 수제 고정 | 런 시작 시 랜덤 |

이 차이에서 나오는 것만 바꾸고 나머지는 원본을 따른다. 원본에 없는 것을 임의로 추가하지 않는다.

## 1. 한 줄 정의

매 웨이브 랜덤으로 주어지는 1성 유닛을 조합해 상위 등급으로 강화하며, 루프를 순회하는 몬스터를 막고 보스를 잡아 최종 보스까지 격파하면 클리어하는 랜덤 디펜스.

---

## 2. 원본에서 확인된 규칙

리서치로 확인된 히랜디 규칙이다. 우리 구현의 근거가 된다.

### 2-1. 조합

- 1성 영웅은 8개 계열: 궁수, 전사, 메카닉, 정령, 마법사, 도적, 격투가, 사제
- 2성은 1성 2기 조합. 같은 계열 2기도 가능하고 다른 계열 2기도 가능하다
  - 스나이퍼 = 궁수 + 궁수, 레인져 = 궁수 + 도적
- 3성부터는 3-4기 조합이며 **등급이 섞인다**
  - 룬나이트 = 격투가(1성) + 화랑(2성) + 마법검사(2성)
  - 워든 = 드루이드(2성) + 전사(1성) + 법사(1성) + 궁수(1성)
- 4성은 3성 위주 3기 조합, 5성 이상은 특수 재화(다크소울)를 요구한다
- 결과물은 특정 계열에 속하며 계열이 유닛의 정체성이다

**핵심: 조합은 같은 등급끼리 짝짓는 것이 아니다.** 상위 등급을 만들려면 하위 등급 재료를 계속 확보해야 하므로, 뽑기가 끝까지 의미를 갖는다.

### 2-2. 도플갱어

맵의 석상을 부수면 드랍된다. 선택 시 원하는 1성 유닛으로 변할 수 있고 공격은 할 수 없다.

원문에 이렇게 적혀 있다. 후반부로 갈수록 도플갱어의 역할이 중요해지는데, 원하는 1성 유닛이 나오지 않아 4성 혹은 심지어 5성까지도 만들지 못하는 상황이 간혹 발생하기 때문이다.

**랜덤 조합 디펜스의 구조적 결함을 정면으로 해결하는 장치다.** 조합 트리가 깊을수록 특정 재료 하나가 안 떠서 막히는 일이 생기는데, 와일드카드가 그걸 푼다. 우리 설계에 반드시 들어가야 한다.

### 2-3. 웨이브

- 스테이지별 총 웨이브는 3, 11, 21, 41, 51, 61, 71, 81, 101로 다양하다
- 1라운드 몬스터는 25기, 1초마다 1마리씩 스폰된다
- **각 웨이브에는 제한시간이 있다.** 제한시간은 기본적으로 다음 웨이브가 시작될 때까지 남은 시간을 뜻한다. 제한시간이 끝나거나 필드 몬스터가 0이 되면(둘 중 먼저 오는 쪽) 다음 웨이브가 시작된다
- **필드에 몬스터가 하나도 없으면 즉시 다음 웨이브가 시작된다.** 이를 통해 클리어 타임을 단축할 수 있다
- 스폰 포인트가 1곳이 아닌 던전도 있고, 이런 던전은 1라운드가 더 빨리 끝나 노가다 장소로 선호된다
- 10의 배수 라운드마다 보스가 등장한다(10, 20, 30, 40 순). 보스 라운드는 매 10라운드마다 오는 독립 시험이다
- **마지막 라운드는 무조건 보스 라운드다.**
- 제한시간 초기값은 35초다. 8x12 직사각형 둘레 경로(36셀)에서 몬스터가 약 1.5바퀴 도는 시간이며 임시값이다

### 2-4. 패배 조건

**보스를 제한시간 내에 처리하지 못하거나, 보스를 잡지 못한 상태에서 다음 보스가 출현하면 패배한다.**

보스 스테이지에서는 웨이브 제한시간이 곧 보스 처치 마감이다. 제한시간이 끝날 때까지 보스를 죽이지 못하면 다음 웨이브로 넘어가지 않고 패배한다. 일반 웨이브는 제한시간이 끝나면 다음 웨이브로 넘어가지만, 보스 웨이브는 제한시간이 끝나면 패배한다는 점이 다르다.

**마지막 라운드에서 보스를 처치하면 웨이브 몬스터가 남아 있어도 즉시 클리어로 판정한다.** 마지막 라운드는 항상 보스 라운드이므로, 보스 처치가 곧 게임 클리어다.

필드 누적 상한이 아니다. 앞선 버전에서 내가 다른 게임(랜덤 인물 디펜스의 50마리 상한)과 혼동했던 부분을 정정한다.

이 방식의 이점은 스노볼이 없다는 것이다. 누적형은 한번 밀리면 회복 불가능한 구간에 들어가지만, 보스 타이머는 10라운드마다 독립 시험이라 매 구간이 새 기회가 된다.

### 2-5. 특수 기믹

스테이지별로 붙는다.

- **특수타일(발판)**: 밟거나 위에 배치하면 버프 또는 디버프. 파란색 버프, 빨간색 디버프. 다만 채도가 너무 높아 눈이 아프다는 불만이 많았다
- **엘리트 몬스터**: 일정 확률로 강화된 개체 등장
- **룰 변경**: 매 웨이브 출현하는 영웅의 등급 또는 수에 변화
- **최초 지급 변동**: 게임 시작 시 주어지는 영웅 수나 등급이 다름
- **유닛 삭제 기믹**: 최종 보스의 블랙홀이 깔린 자리에 있던 유닛은 등급 불문 삭제된다

### 2-6. 랭킹 모드 (고난의 탑)

1. 필드 내 몬스터 수가 0이 되면 바로 다음 웨이브가 시작된다
2. 다음 웨이브를 빨리 진행시킬수록 추가 점수를 받는다
3. 마지막 웨이브는 몬스터가 계속 출현하며 오래 버틸수록 추가 점수를 받는다
4. 스킵은 사용할 수 없다
5. 매 웨이브 일정 확률로 엘리트 몬스터가 등장한다

## 3. 우리 구현

### 3-0. 런 시작 전 (예약)

**현재 준비 단계가 없다. 런은 즉시 시작된다.**

맵만 시드로 생성되고 플레이어가 사전에 선택할 것이 없다. 덱 시스템을 검토했으나 1성이 6종뿐이라 6종 선택은 의미가 없어 폐기했다. 원본에도 사전 선택이 없다.

이 자리는 비워두되 나중에 채운다.

| 예정 항목 | 상태 |
|---|---|
| 히어로 유닛 선택 | 보류. 코어 검증 후 별도 설계 |
| 특성 선택 | 보류. 원본의 특성 시스템에 해당 |

**지금 임시로 뭔가를 채우지 않는다.** 코어가 재미있는지부터 확인하고, 그 위에 준비 단계를 얹는다. 준비 단계가 있어야 재미있는 게임이라면 코어에 문제가 있는 것이다.

다만 구현할 때 **런 시작 진입점에 준비 단계가 들어갈 자리를 남겨둔다.** 나중에 화면 하나를 끼워 넣을 수 있도록 씬 전환과 런 초기화를 분리해 설계한다.

### 3-1. 계열

원본 8계열을 6계열로 줄인다. 1인 개발 규모에 맞춘 축소이며 구조는 동일하다.

| 계열 | 성격 |
|---|---|
| 전사 | 근거리 단일 고피해 |
| 궁수 | 원거리 단일, 사거리 우수 |
| 법사 | 광역 피해 |
| 사제 | 아군 강화, 적 약화 |
| 도적 | 고속 공격, 치명타 |
| 정령 | 지속 피해, 상태이상 |

계열은 유닛의 정체성이자 조합식의 재료 조건이다. 속성이나 역할 같은 별도 축은 두지 않는다. 원본에 없다.

### 3-2. 등급과 종수

| 등급 | 종수 | 조합 재료 | 비고 |
|---|---|---|---|
| 1성 | 6종 | 뽑기로만 획득 | 계열당 1종 |
| 2성 | 12종 | 1성 2기 | 같은 계열 또는 다른 계열 |
| 3성 | 12종 | 3기 (1성과 2성 혼합) | |
| 4성 | 8종 | 3기 (2성과 3성 혼합) | |
| 5성 | 4종 | 4기 (3성과 4성 혼합) | 런의 최종 목표 |
| 도플갱어 | 1종 | 석상 파괴로 획득 | 원하는 1성으로 변환. 공격 불가 |

총 43종. 5성 4종이 클라이맥스이고, 각각 다른 계열 조합을 요구해 목표 설정이 갈리게 한다.

**원본의 다크소울에 해당하는 특수 재화는 두지 않는다.** 5성도 일반 유닛 조합만으로 도달한다. 재화 병목을 넣으면 조합 트리 외부에 또 하나의 진행 축이 생겨 코어가 흐려진다.

### 3-3. 조합 규칙

- 조합 재료는 2기에서 4기까지. 등급이 섞일 수 있다
- 조합식은 고정이다. 같은 재료는 항상 같은 결과를 낸다
- 재료는 소모된다
- 조합은 언제든 가능하다. 웨이브 진행 중에도 제한이 없다
- 도감에 발견한 조합식이 기록되고, 다음 런부터 힌트가 표시된다

### 3-4. 유닛 배치와 이동

**좌표계를 두 겹으로 둔다.** 배치는 그리드 단위로 이산적이고 실제 이동은 연속적이다.

| 좌표 | 단위 | 용도 |
|---|---|---|
| 논리 좌표 | 그리드 셀 인덱스 | 배치, 회수, 특수타일 판정, UI 히트 테스트 |
| 물리 좌표 | Fixed 연속값 | 실제 위치, 이동, 사거리 판정, 겹침 해소 |

**배치**

- 유닛은 BUILD 타입 셀에 배치한다. 그 셀 중심이 홈 포지션이 된다
- **한 셀에는 유닛 1기만 놓을 수 있다.** 셀이 한정 자원이므로 배치가 결정이 된다
- 배치 타일 종류 구분은 없다. 특수타일만 예외
- 언제든 회수 가능. 코스트 50% 환불

**이동은 명령 기반이다. 자동 추적하지 않는다.**

유닛은 두 가지 상태를 갖는다.

| 상태 | 동작 |
|---|---|
| 대기 (기본) | 홈 포지션을 지킨다. 사거리 안에 들어온 몬스터만 공격한다 |
| 집중 (명령 시) | 지정된 대상에게 이동해 사거리에 들어갈 때까지 접근하고 공격한다 |

- **기본 상태가 대기다.** 명령이 없으면 유닛은 절대 자리를 벗어나지 않는다
- 집중 명령은 개별 유닛에도, 전체에도 내릴 수 있다
- 대상이 죽거나 명령을 해제하면 홈 포지션으로 복귀한다
- 복귀 중에도 사거리 안 몬스터는 공격한다

**이 구조가 배치 게임과 능동 조작을 동시에 성립시킨다.**

- 대기 상태가 기본이므로 커버 효율이 배치의 핵심으로 유지된다. 자동 추적이면 어디에 놓든 쫓아가므로 배치가 의미를 잃는다
- 집중 명령이 플레이어의 전투 중 능동 행동이 된다. 마법과 함께 관전 시간을 채운다
- **전체 집중 명령이 보스전의 핵심 플레이가 된다.** 보스 제한시간 안에 화력을 몰아넣는 것이 승패를 가른다

**이동 처리**

- 이동은 연속 좌표로 처리한다. 그리드 칸을 밟아 가는 방식이 아니다
- 경로 탐색은 하지 않는다. 대상 방향으로 직선 이동하고 장애물은 반발로 회피한다
- 이동 속도는 계열별로 다르다. 근접 계열이 빠르다

**계열 차별화**

| 계열 성향 | 사거리 | 이동 속도 | 집중 명령 체감 |
|---|---|---|---|
| 근접 (전사, 도적) | 짧음 | 빠름 | 즉시 달려가 붙는다 |
| 원거리 (궁수, 법사) | 김 | 느림 | 조금만 움직여도 사거리에 든다 |
| 보조 (사제, 정령) | 중간 | 중간 | |

원거리 계열은 사거리가 길어 집중 명령을 내려도 거의 움직이지 않는다. 근접 계열은 자리를 크게 비우게 되므로 명령 자체가 저울질이 된다.

**겹침 방지**

- 모든 유닛은 반경 r의 원형 점유 영역을 갖는다
- 매 틱 겹침을 검사해 서로 밀어낸다
- **물리 엔진을 쓰지 않는다.** 결정성이 깨진다
- 유닛을 셀 인덱스 오름차순으로 순회하며 순차적으로 분리한다. 순회 순서가 고정이므로 결과가 재현된다
- **몬스터는 겹칠 수 있다.** 원본에서 대열로 보이는 것은 스폰 주기를 간격이 벌어지도록 조절한 결과이며, 처리가 밀려 많이 쌓이면 실제로 겹친다
- 따라서 분리 처리나 추월 금지를 강제하지 않는다. 스폰 간격으로만 통제한다
- **밀집 자체가 위기 신호가 된다.** 화면에 몬스터가 뭉치기 시작하면 처리량이 부족하다는 뜻이므로, 별도 게이지 없이 상황이 읽힌다

**전투**

- **벽이나 저지 역할 유닛은 만들지 않는다.** 몬스터는 아무것도 막지 않고 루프를 계속 돈다
- 몬스터는 아군을 공격하지 않는다. 유닛은 죽지 않는다
- 예외: 특정 보스의 광역 기믹에 걸린 자리의 유닛은 삭제될 수 있다 (원본 블랙홀에 해당)
- 타겟 우선순위: 사거리 안에서 진행 방향 기준 가장 앞선 몬스터, 동률이면 가장 가까운 개체. 유효 타겟이 있으면 더 먼 선호 대상으로 우회하지 않는다

### 3-4-1. 창고

원본에 존재하는 편의 기능이다. 화면 좌상단의 정리 버튼으로 호출한다.

- **1성 유닛을 일괄적으로 창고에 넣을 수 있다**
- 창고 유닛은 필드와 인벤토리에서 빠지지만 조합 재료로는 그대로 쓸 수 있다
- 언제든 꺼낼 수 있다

1성은 조합 재료로 끝까지 필요하지만 개별 전투력은 후반에 무의미해진다. 그대로 두면 인벤토리가 1성으로 가득 차 상위 유닛이 안 보인다. 창고가 그 정리 부담을 한 번에 없앤다.

**보유 유닛 상한은 두지 않는다.** 조합 압박은 다른 데서 나온다. 1성을 쌓아두면 그만큼 필드 전력이 약해지고 웨이브를 못 막는다. 별도 제한 없이도 합칠 이유가 충분하다.

### 3-5. 웨이브

- 총 40웨이브. 원본 스테이지 중 중간 규모를 기준으로 잡았다
- 1웨이브 몬스터 25기, 1초마다 1기씩 스폰. 웨이브 번호에 따라 수와 능력치가 증가한다
- **필드 몬스터가 0이 되면 즉시 다음 웨이브가 시작된다.** 빨리 정리할수록 런이 짧아진다
- 스폰 포인트는 맵에 따라 1-3곳. 여러 곳이면 유입이 빨라 웨이브가 빨리 끝나지만 배치가 분산된다
- 스킵 기능: 대기 시간을 건너뛰고 다음 웨이브를 즉시 시작한다
- **웨이브 시작 전 이번 몬스터의 이름과 특성을 미리 표시한다.** 원본이 그렇다. 방어력 증가 같은 특성을 알려주므로 조합 방향을 미리 정할 수 있다
- 엘리트 몬스터가 일정 확률로 섞여 나온다

목표 플레이 타임 25-35분. 스킵을 적극 쓰면 20분 이하로도 가능하다.

### 3-6. 보스와 승패

- 10, 20, 30, 40웨이브에 보스가 등장한다(10의 배수)
- 보스도 루프를 순회한다. 별도 경로나 각성 연출은 없다
- 보스 웨이브에는 화면 상단에 목표와 남은 시간이 표시된다. 원본은 "리자드킹 처치 0/1" 형태로 보여준다
- **패배**: 보스를 제한시간 내에 처리하지 못하거나, 이전 보스를 잡지 못한 상태에서 다음 보스가 출현
- **승리**: 40웨이브 최종 보스 격파
- 보스 격파 시 도플갱어와 마법을 지급한다

### 3-7. 마법

원본의 마법 시스템을 계승한다. 히어로를 보류한 상태에서 **플레이어의 유일한 능동 개입 수단**이므로 중요도가 높다.

- 마나가 시간에 따라 회복된다
- 마법을 발동해 즉시 효과를 낸다
- 런 시작 시 마법 3종을 보유하고, 석상과 보스 보상으로 추가 획득한다

마법 계열:

| 계열 | 예시 |
|---|---|
| 정리계 | 필드 몬스터에 즉시 피해. 위기 대응 |
| 조합계 | 1성 1기 즉시 지급, 도플갱어 즉시 지급 |
| 강화계 | 일정 시간 전체 공격력 증가 |
| 감속계 | 일정 시간 몬스터 이동 속도 감소 |

정리계가 죽음의 스파이럴 방어 장치다.

### 3-8. 특수 타일

- 맵에 버프 타일과 디버프 타일이 랜덤 배치된다
- 버프 타일에 유닛을 놓으면 능력치가 상승하고, 디버프 타일은 하락한다
- **색상 채도로 구분하지 않는다.** 원본이 실제로 지적받은 지점이다. 명도 대비, 높이차, 외곽선으로 구분한다
- 배치 최적해를 매 런 다르게 만드는 주 변수다

### 3-9. 석상

- 맵 외곽에 석상이 1-2개 배치된다
- 유닛 사거리 안에 들어오면 공격이 시작되고, 파괴하면 도플갱어 또는 마법을 드랍한다
- 석상은 반격하지 않는다. 다만 사거리를 석상에 쓰는 동안 루프 커버가 줄어드는 것이 비용이다

### 3-10. 맵

- 루프형 폐곡선. 런 시작 시 시드로 생성된다
- 위상은 고정 셋 3-4종 (단순 링, 8자, 이중 루프 등). 그 안에서 형태가 변주된다
- 랜덤화 대상: 위상 선택, 변의 길이와 요철, 특수 타일 위치, 스폰 포인트 수와 위치, 석상 위치
- 상세는 MAP_SPEC.md
- **런 도중 맵은 바뀌지 않는다.** 액트 분할은 하지 않는다

### 3-11. 메타 진행

로그라이트이므로 원본의 계정 성장(영혼석, 유물 강화, 특성)은 대부분 가져오지 않는다.

- 조합 도감 해금. 발견한 조합식이 다음 런부터 힌트로 표시된다
- 마법 해금. 런 시작 시 선택할 수 있는 마법 풀이 늘어난다
- 난이도 승급. 클리어할 때마다 1단계씩
- **유닛 능력치 영구 강화는 넣지 않는다**

### 3-12. 무한 모드

원본의 고난의 탑 규칙을 그대로 따른다.

- 40웨이브 완주 후 해금
- 마지막 웨이브 이후 몬스터가 계속 출현하며 오래 버틸수록 점수가 오른다
- 빨리 진행시킬수록 추가 점수
- 스킵 사용 불가
- 매 웨이브 일정 확률로 엘리트 몬스터 등장
- 로컬 리더보드에 기록

## 4. 맵 구성

### 4-1. 그리드

- 16 x 12 셀. 화면에는 마름모로 45도 회전되어 표시된다
- 논리 좌표는 회전 전 축 정렬 기준으로 다룬다. 회전은 표시 단계에서만 적용한다

### 4-2. 셀 타입

| 타입 | 설명 | 배치 |
|---|---|---|
| PATH | 몬스터가 순회하는 루프 경로 | 불가 |
| BUILD | 일반 배치 가능 셀 | 가능 |
| BUFF | 능력치 상승 특수타일 | 가능 |
| DEBUFF | 능력치 하락 특수타일 | 가능 |
| BLOCK | 장애물, 장식 | 불가 |
| SPAWN | 몬스터 유입 지점. PATH 위에 얹힌다 | 불가 |
| STATUE | 석상. 파괴 대상 | 불가 |

### 4-3. 루프

- PATH 셀이 이루는 폐곡선. 시작점도 끝점도 없다
- 몬스터는 루프 웨이포인트를 따라 순회한다. 마지막 웨이포인트 다음은 처음으로 돌아간다
- 위상은 고정 셋 3-4종에서 런 시작 시 하나를 뽑고, 그 안에서 형태가 변주된다

### 4-4. 배치 영역

**루프 안쪽과 바깥쪽 모두 배치할 수 있다.** 성격이 다르다.

- 안쪽: 여러 변을 동시에 커버할 수 있어 효율이 높다. 특히 코너 안쪽이 핫스팟이다
- 바깥쪽: 한 변만 커버하지만 석상 접근이 가능하고 공간이 넓다

이 선택이 배치 결정의 첫 갈래가 된다.

### 4-5. 특수타일

- 버프 타일과 디버프 타일이 맵에 랜덤 배치된다
- 유닛을 올려두면 능력치가 상승하거나 하락한다
- **색상 채도로 구분하지 않는다.** 원본이 지적받은 지점이다. 명도 대비, 높이차, 외곽선으로 구분한다
- 디버프 타일은 좋은 커버 지점에 배치되는 경향을 준다. 좋은 자리인데 페널티가 붙는 저울질을 만들기 위함이다

### 4-6. 석상

- 맵 외곽에 1-2개 배치된다
- 유닛 사거리 안에 들어오면 자동으로 공격이 시작되고, 파괴하면 도플갱어 또는 마법을 드랍한다
- 석상은 반격하지 않는다
- 비용은 사거리를 석상에 쓰는 동안 루프 커버가 줄어드는 것이다

### 4-7. 스폰 포인트

- 맵에 따라 1-3곳. 루프 위에 배치된다
- 여러 곳이면 유입이 빨라져 웨이브가 빨리 끝나지만 몬스터가 루프 전체에 분산되어 배치가 어려워진다
- 스폰 수는 난이도 변수이자 클리어 속도 변수다

### 4-8. 랜덤화 대상

런 시작 시 시드로 결정된다.

- 루프 위상 선택 (고정 셋 3-4종 중 하나)
- 선택된 위상 내 형태 변주 (변의 길이, 요철)
- 특수타일 종류와 위치
- 스폰 포인트 수와 위치
- 석상 위치

**런 도중에는 맵이 바뀌지 않는다.**

상세 생성 알고리즘은 MAP_SPEC.md 참조.

## 5. 조작

터치와 마우스가 동일한 경로로 처리된다. 정밀 좌표 지정이 필요한 조작은 넣지 않는다.

| 조작 | 입력 | 비고 |
|---|---|---|
| 유닛 선택 | 탭 | 사거리 범위가 표시된다 |
| 개별 집중 명령 | 유닛 선택 후 몬스터 탭 | 해당 유닛만 대상에게 접근해 공격 |
| 전체 집중 명령 | 전체 명령 버튼 후 몬스터 탭 | 모든 유닛이 대상에게 화력을 몰아준다. 보스전 핵심 |
| 명령 해제 | 빈 셀 탭 또는 해제 버튼 | 전원 홈 포지션 복귀 |
| 배치 | 인벤토리에서 셀로 드래그, 또는 탭 후 셀 탭 | 배치 가능 셀이 발광한다 |
| 이동 | 배치된 유닛을 다른 빈 셀로 드래그 | 코스트 소모 없음 |
| 회수 | 유닛을 인벤토리 영역으로 드래그, 또는 롱프레스 | 코스트 50% 환불 |
| 조합 | 조합 패널에서 결과물 선택 후 실행 | 재료가 자동 선택된다 |
| 마법 발동 | 마법 버튼 탭. 대상 지정형은 이후 셀 탭 | |
| 1성 정리 | 버튼 | 보유한 1성 유닛을 일괄 창고로 보낸다 |
| 스킵 | 버튼 | 대기 시간을 건너뛴다 |
| 배속 | 버튼 | 1배, 2배, 3배 |
| 일시정지 | 버튼 | 옵션 진입 |

**조합 UI는 결과물 기준으로 만든다.** 재료를 골라서 뭐가 나오는지 보는 방식이 아니라, 만들 수 있는 결과물 목록을 보여주고 선택하면 재료가 자동으로 소모되는 방식이다. 조합식이 43종에 재료가 최대 4기이므로 재료 기준 UI는 조작 부담이 크다.

조합 패널은 세 구역으로 나눈다.

- **지금 만들 수 있는 것**: 재료가 전부 있는 조합식
- **하나만 더 있으면 되는 것**: 재료 1기가 부족한 조합식. 무엇이 부족한지 표시한다
- **도감**: 발견한 전체 조합식

창고에 있는 1성도 재료 판정에 포함한다. 창고에 넣었다고 조합이 막히면 정리 기능의 의미가 없다.

두 번째 구역이 핵심이다. 다음 목표를 플레이어에게 직접 알려주므로 뽑기 결과를 볼 때마다 기대가 생긴다.

## 7. 스코프 경계

만들지 않는 것을 명시한다. 이 목록에 있는 것을 구현하자는 제안이 나오면 거절한다.

- **히어로 유닛 시스템.** 보류 상태이며 이 문서에서 다루지 않는다. 코어 검증 후 별도 문서로 설계한다
- **벽 또는 저지 역할 유닛.** 몬스터는 아무것도 막지 않는다
- 유닛 이동 명령. 유닛은 배치 지점에 고정된다
- 오펜스 요소 일체. 구역 해금, 파견, 원정, 전선
- 액트 분할. 런 도중 맵이 바뀌지 않는다
- 멀티플레이, 온라인 대전 (리더보드 점수 업로드는 예외)
- 인앱 결제, 광고, 가챠 상점

## 8. 플랫폼 제약

### 8-1. 개발 기준

모바일 제약으로 개발하고 스팀으로 출시한다.

| 항목 | 목표 |
|---|---|
| 타겟 실기 | 중저사양 안드로이드 1종 고정 |
| 프레임 | 실기 30fps 하한 |
| 드로우콜 | 전투 화면 150 이하 |
| SetPass Call | 30 이하 |
| 텍스처 메모리 | 200MB 이하 |

**동시 표시 몬스터 80기가 성능 상한 기준이다.** 원본 1라운드가 25기이고 후반 웨이브는 그보다 많으므로 여유를 둔다. 순회 몬스터는 GPU 인스턴싱으로 처리한다.

### 8-2. 카메라

- **직교 투영, 마름모 45도 회전 그리드.** 원본과 동일하며 화면 네 모서리에 UI 공간이 생긴다
- 하향각은 원본보다 약간 세운다. 집중 명령으로 대상 몬스터를 탭해야 하므로 대열이 겹쳐 보이면 안 된다
- 기본은 맵 전체가 한 화면에 들어오는 고정 뷰다
- **제한적 팬과 줌을 허용한다.** 원본도 시야 조정이 가능하다. 다만 맵 밖으로 나가지 못하게 경계를 두고, 조작 후 일정 시간이 지나면 기본 뷰로 복귀한다
- UI는 세로와 가로 레이아웃을 모두 지원하는 앵커 설계

### 8-3. 입력

- 터치와 마우스를 동시에 받는 추상화 레이어를 처음부터 구축한다
- 조작 목록은 5장 참조. 드래그와 탭만 쓰며 정밀 좌표 지정이 없다
