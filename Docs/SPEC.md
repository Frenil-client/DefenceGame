배치 위치: Docs/SPEC.md / 버전 0.3

## 1. 한 줄 정의

덱에서 뽑힌 유닛을 합성해 루프를 도는 몬스터를 처리하고, **그 합성이 곧 내 히어로를 키우는** 랜덤 디펜스.

## 2. 장르 좌표

원피스 랜덤 디펜스와 히어로즈 랜덤 디펜스의 구조를 그대로 계승한다. 랜덤 뽑기, 등급 합성, 루프 순회 몬스터, 필드 누적 실패 조건이 전부 그 계보의 표준 문법이다.

**차별점은 히어로 하나다.**

1. 유닛을 합성할 때마다 히어로가 성장한다. 합성이 방어 전력과 캐릭터 육성 두 가지를 동시에 준다
2. 히어로는 직접 싸우면서 동시에 주변 아군에게 오라 버프를 준다. 히어로를 어디에 놓느냐가 배치 퍼즐의 중심축이 된다
3. 히어로 스킬이 필드 누적을 정리하는 주 수단이다. 위기 관리가 히어로에 집중된다

이 셋 외에는 검증된 장르 문법을 그대로 따른다. 새로 발명하지 않는다.

## 3. 코어 루프

### 3-1. 런 시작 전

1. **히어로 선택** - 5명 중 1명. 스킬 카드 풀과 오라 성격이 다르다
2. **덱 구성** - 흔함 10종 중 6종을 골라 뽑기 풀을 정한다
3. **맵 생성** - 시드로 루프 맵이 생성된다. 코너 위치와 스폰 위치가 매 런 다르다

### 3-2. 웨이브 루프 (30-45초)

1. **뽑기** - 웨이브 시작 시 덱 안에서 흔함 유닛 1기 지급
2. **합성** - 상위 등급 생성. 히어로 경험치가 함께 들어온다
3. **히어로 레벨업** - 경험치가 차면 스킬 카드 3택 1
4. **배치** - 루프 내부 배치 타일에 놓는다. 사거리로 루프를 커버하는 것이 전부다
5. **전투** - 자동 진행. 몬스터는 죽을 때까지 루프를 계속 돈다
6. **정산** - 킬 보상, 코스트 회복

준비와 전투를 페이즈로 나누지 않는다. 몬스터가 항상 필드에 있으므로 전투는 끊기지 않고, 플레이어는 언제든 뽑기와 합성과 배치를 할 수 있다.

### 3-3. 런 구조

- 30웨이브. 목표 플레이 타임 25-35분
- 10, 20, 30웨이브에 보스가 루프에 투입된다
- 30웨이브 보스를 격파하면 승리
- 완주 후 무한 모드 해금

## 4. 실패와 승리

### 4-1. 실패

**필드에 살아 있는 몬스터 수가 상한(60)에 도달하면 패배한다.**

몬스터는 루프를 끝없이 돈다. 목적지가 없고 누출도 없다. 처리하지 못한 몬스터는 사라지지 않고 계속 쌓인다. 실패는 순간적인 방어선 붕괴가 아니라 **처리량 부족의 누적**이다.

이 방식의 이점:

- 실패가 갑자기 오지 않는다. 게이지가 서서히 차므로 플레이어가 위기를 미리 안다
- 전투에 공백이 없다. 필드에 항상 적이 있다
- 킬이 자원이다. 누적을 감수하고 라인딜로 한 번에 수확하는 고급 플레이가 성립한다

### 4-2. 승리

30웨이브 보스 격파.

### 4-3. 죽음의 스파이럴 방어

누적이 쌓이면 처리량이 더 부족해지는 양의 피드백이 있다. 다음 세 가지로 제동한다.

- 히어로 스킬 중 라인딜 계열 (범위 내 순회 몬스터 전체 타격)
- 라인딜 유닛 계열을 조합 트리에 반드시 배치
- 긴급 유물 (누적 절반 정리, 런당 1회)

## 5. 시스템 목록

### 5-1. 맵

- 루프형 폐곡선. 시작점도 끝점도 없다
- 시드 기반 랜덤 생성. 상세는 MAP_SPEC.md
- 배치 영역은 루프 내부
- 스폰은 루프 위 3곳. 파괴 대상이 아니라 단순 유입 지점이다

### 5-2. 덱

- 런 시작 전 흔함 10종 중 6종 선택. 뽑기는 이 안에서만 나온다
- 덱 슬롯 기본 6칸, 메타 해금으로 7칸
- 덱 구성 화면에서 도달 가능한 레어, 유니크, 히든 수를 실시간 표시한다
- 도달 가능 조합이 적은 덱도 막지 않는다

### 5-3. 유닛과 합성

- 4단 등급: 흔함 10종, 레어 12종, 유니크 6종, 히든 6종
- 합성은 2기 결합. 흔함 2기는 같은 속성 또는 같은 역할이면 성립, 그 위는 고정 레시피
- 3합체는 넣지 않는다. 결정이 없기 때문이다
- 상세: BALANCE_SPEC.md 4장

### 5-4. 배치

- 루프 내부 배치 타일 어디든 놓을 수 있다. **타일 종류 제약이 없다**
- 배치 코스트만 소모한다
- 유닛은 죽지 않는다. 순회 몬스터가 아군을 공격하지 않는다
- 배치의 전부는 **사거리로 루프를 얼마나 커버하는가**이다. 코너 안쪽이 핫스팟이 된다
- 언제든 회수 가능. 코스트 50% 환불

### 5-5. 히어로

- 런 시작 시 5명 중 1명 선택. 배치 코스트 0
- **직접 전투에 참여하면서 동시에 반경 R 안의 아군에게 오라 버프를 준다**
- 유닛을 합성할 때마다 경험치를 얻는다. 적 처치로는 얻지 않는다
- 레벨업 시 스킬 카드 3택 1. 카드 풀은 히어로마다 다르다
- 특정 카드 2장을 모두 보유하면 진화한다
- 플레이어가 조작하지 않는다. 배치 위치만 정한다
- 상세: BALANCE_SPEC.md 7장

**히어로 배치가 이 게임의 핵심 결정이다.** 코너 핫스팟(커버 효율)과 오라 반경(아군 밀집도)의 교집합을 찾는 문제이며, 맵이 매 런 다르므로 정답도 매번 다르다.

### 5-6. 로그라이트

- 유물 80-100종 (규칙 변경형)
- 메타 해금: 합성 도감, 히어로 해금, 덱 슬롯 확장, 덱 편성 유닛 해금
- 난이도 승급 1부터 5
- 무한 모드 + 로컬 리더보드
- **스탯 영구 강화는 넣지 않는다**

### 5-7. 내러티브

- 보스 등장 전후 짧은 대사
- 로비 대화 (런 종료 시 1편 해금). 선택지는 캐릭터 반응만 바꾸고 스토리 분기는 만들지 않는다
- 히든 유닛 최초 합성 시 등장 연출과 대사
- 히어로 스킬 진화 시 짧은 연출

## 6. 스코프 경계

만들지 않는 것을 명시한다. 이 목록에 있는 것을 구현하자는 제안이 나오면 거절한다.

- 멀티플레이, 온라인 대전 (리더보드 점수 업로드는 예외)
- 인앱 결제, 광고, 가챠 상점
- **오펜스 요소 일체.** 구역 해금, 파견, 원정, 전선 이동, 스폰 파괴, 사이드 목표
- 플레이어가 조작하는 히어로. 히어로는 배치만 하고 자동으로 싸운다
- 유닛 이동 명령. 유닛은 배치 지점에 고정된다
- 3합체 시스템
- 스탯 영구 강화 메타
- 순회 몬스터의 아군 공격 (일방적 처리 대상으로 둔다)
- 세이브 슬롯 다중 관리

## 7. 플랫폼 제약

### 7-1. 개발 기준

모바일 제약으로 개발하고 스팀으로 출시한다.

| 항목 | 목표 |
|---|---|
| 타겟 실기 | 중저사양 안드로이드 1종 고정 |
| 프레임 | 실기 30fps 하한 |
| 드로우콜 | 전투 화면 150 이하 |
| SetPass Call | 30 이하 |
| 텍스처 메모리 | 200MB 이하 |

**동시 표시 몬스터 60기가 성능 상한 기준이다.** 순회 몬스터는 GPU 인스턴싱으로 처리하고, 누적 상태 몬스터는 이펙트를 줄여 그린다.

### 7-2. 입력

- 터치와 마우스를 동시에 받는 추상화 레이어
- 조작은 선택, 배치, 회수, 합성, 카드 선택만

### 7-3. 화면

- 고정 쿼터뷰. **맵 전체가 한 화면에 들어온다. 카메라 이동도 줌도 없다**
- 루프형이라 맵 크기가 고정 범위 안에 있으므로 이게 가능하다
- UI는 세로와 가로 레이아웃을 모두 지원하는 앵커 설계

## 8. 용어집

| 용어 | 영문 | 의미 |
|---|---|---|
| 흔함 / 레어 / 유니크 / 히든 | Common / Rare / Unique / Hidden | 4단 등급 |
| 합성 | Fusion | 유닛 2기를 상위 유닛으로 결합 |
| 레시피 | Recipe | 합성식 |
| 덱 | Deck | 런 시작 전 선택하는 흔함 6종 |
| 히어로 | Hero | 필드 상주 캐릭터. 합성으로 성장 |
| 오라 | Aura | 히어로 반경 내 아군 버프 |
| 스킬 카드 | SkillCard | 히어로 레벨업 시 3택 1로 획득 |
| 진화 | Evolve | 특정 카드 2장 보유 시 상위 스킬로 승격 |
| 루프 | Loop | 몬스터가 순회하는 폐곡선 |
| 누적 | Accumulation | 필드에 살아 있는 몬스터 수 |
| 커버 | Coverage | 배치 타일에서 사거리 안에 들어오는 루프 타일 수 |
| 핫스팟 | Hotspot | 커버가 높은 배치 타일. 주로 코너 안쪽 |
| 승급 | Ascension | 클리어 시 열리는 난이도 단계 |
