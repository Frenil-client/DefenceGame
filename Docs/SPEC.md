# SPEC.md

SYNTHESIS (가칭) - 게임 사양

배치 위치: Docs/SPEC.md

---

## 1. 한 줄 정의

랜덤으로 지급되는 유닛을 조합해 상위 유닛을 만들며 24웨이브를 막고, 잠들어 있는 보스 3기를 언제 어떻게 만날지 스스로 정하는 디펜스 로그라이트.

---

## 2. 코어 루프

### 2-1. 웨이브 루프 (40-60초)

1. **뽑기** - 웨이브 종료 시 흔함 유닛 1기 지급
2. **조합** - 보유 유닛을 조합해 상위 등급 생성. 무엇을 만들 것인가가 결정
3. **배치** - 근접칸과 원거리칸에 배치. 코스트 소모
4. **전투** - 자동 진행. 플레이어는 배치와 파견 명령만
5. **정산** - 코스트 회복, 재배치 쿨타임 진행

### 2-2. 런 구조

| 웨이브 | 내용 |
|---|---|
| 1-7 | 축적 구간 / 공세 창 1 |
| 8 | 보스 1 - 강철 성채 (장갑형) |
| 9-15 | 축적 구간 / 공세 창 2 |
| 16 | 보스 2 - 창공의 눈 (비행형) |
| 17-23 | 축적 구간 / 공세 창 3 |
| 24 | 보스 3 - 잠든 왕 (최종) |

목표 플레이 타임 25-35분. 런 시작 시 리더 1명을 선택한다.

---

## 3. 시스템 목록

### 3-1. 유닛과 조합

- 4단 등급: 흔함 10종, 레어 12종, 유니크 6종, 히든 6종
- 조합은 2기 합성. 흔함 2기는 같은 속성 또는 같은 역할이면 성립, 그 위는 고정 레시피
- 3합체는 넣지 않는다. 결정이 없기 때문이다
- 상세: BALANCE_SPEC.md 4장

### 3-2. 배치

- 그리드 맵. 경로 타일, 근접칸, 원거리칸, 장애물
- 배치 코스트, 저지 수, 배치 타일 종류의 3제약
- 유닛은 죽으며 재배치 쿨타임이 있다
- 회수 시 코스트 50% 환불

### 3-3. 보스

- 맵의 스폰 포인트 3개가 곧 잠든 보스 3기
- 평시에는 해당 속성의 적을 뿜어내고, 정해진 웨이브에 각성해 전진한다
- 각성 전까지 입힌 피해가 반영된다. 사전 타격 상한은 최대 HP의 40%
- 각성 전에 처치하면 보스전이 공략전 형태로 대체된다
- 보스는 고정이며 셔플하지 않는다

### 3-4. 공세

- 맵은 구역으로 나뉘고 시작 시 본진 구역만 배치 가능
- 돌격 속성 유닛을 다음 구역으로 파견한다. 이동 5-8초, 이동 중 무방비
- 도착 성공 시 그 구역 영구 해금
- 스폰 인접 구역을 해금하면 보스를 사거리에 넣을 수 있다
- 보상: 보스 사전 타격, 해당 속성 뽑기 가중치 2배, 히든 조합식 해금, 리롤권

### 3-5. 리더

- 런 시작 시 4-6명 중 1명 선택
- 뽑기 풀 가중치, 조합 특전, 시작 유닛 2종, 고유 패시브를 바꾼다
- **필드에 등장하지 않는다.** UI와 대화 화면에만 나온다

### 3-6. 로그라이트

- 유물 40-50종 (규칙 변경형)
- 메타 해금: 조합 도감, 리더 해금, 난이도 승급
- **스탯 영구 강화는 넣지 않는다**

### 3-7. 내러티브

- 보스 대면 대사 (각성 직전, 격파 후)
- 로비 대화 (런 종료 시 1편 해금). 선택지는 캐릭터 반응만 바꾸고 스토리 분기는 만들지 않는다
- 히든 유닛 최초 조합 시 등장 연출과 대사

## 4. 스코프 경계

**만들지 않는 것을 명시한다.** 이 목록에 있는 것을 구현하자는 제안이 나오면 거절한다.

- 멀티플레이, 온라인 기능, 랭킹 서버
- 인앱 결제, 광고, 가챠 상점
- 절차적 맵 생성 (맵은 데이터로 정의된 고정 셋)
- 노드 선택형 로그라이트 맵 (검토했으나 폐기)
- 플레이어가 직접 조작하는 히어로 캐릭터 (별도 제안 B의 영역)
- 3합체 시스템
- 스탯 영구 강화 메타
- 보스 랜덤화 및 셔플
- 세이브 슬롯 다중 관리 (런 진행 저장 1개면 충분)

## 5. 플랫폼 제약

### 5-1. 개발 기준

**모바일 제약으로 개발하고 스팀으로 출시한다.**

| 항목 | 목표 |
|---|---|
| 타겟 실기 | 중저사양 안드로이드 1종 고정 |
| 프레임 | 실기 30fps 하한 |
| 드로우콜 | 전투 화면 150 이하 |
| SetPass Call | 30 이하 |
| 텍스처 메모리 | 200MB 이하 |
| 빌드 사이즈 | 초기 다운로드 300MB 이하 |

수치는 STEP 2 완료 시점에 실측으로 재조정한다.

### 5-2. 입력

- 터치와 마우스를 동시에 받는 추상화 레이어를 처음부터 구축한다
- 조작은 선택, 배치, 회수, 파견 명령만. 실시간 조작 없음

### 5-3. 화면

- 고정 쿼터뷰. 카메라 이동 없음
- **맵 전체가 한 화면에 들어와야 한다.** 공세 중에도 방어선 상황이 보여야 판단이 성립한다
- UI는 세로와 가로 레이아웃을 모두 지원하는 앵커 설계

## 6. 용어집

코드와 문서에서 아래 용어를 통일해서 쓴다.

| 용어 | 영문 | 의미 |
|---|---|---|
| 흔함 | Common | 최하위 등급. 속성 부품 |
| 레어 | Rare | 2단계 등급 |
| 유니크 | Unique | 3단계 등급 |
| 히든 | Hidden | 최상위 등급. 고유 캐릭터 |
| 조합 | Combine | 유닛 2기를 상위 유닛으로 합성 |
| 레시피 | Recipe | 조합식 |
| 저지 | Block | 근접 유닛이 적을 붙잡아 세우는 것 |
| 구역 | Zone | 배치 가능 영역 단위. 0이 본진, 숫자가 클수록 전방 |
| 파견 | Advance | 유닛을 다음 구역으로 보내 해금하는 행위 |
| 각성 | Awaken | 스폰 포인트가 보스로 변하는 것 |
| 사전 타격 | PreDamage | 각성 전에 스폰에 입힌 피해 |
| 리더 | Leader | 런 시작 시 선택하는 캐릭터 |
| 승급 | Ascension | 클리어 시 열리는 난이도 단계 |
