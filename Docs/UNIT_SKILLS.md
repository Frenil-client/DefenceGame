# UNIT_SKILLS.md

프로젝트: SYNTHESIS - 유닛 스킬 분배 (v0.4)

배치 위치: Docs/UNIT_SKILLS.md

원본은 Data/skills.csv (스킬 정의) 와 Data/units.csv 의 skillIds 컬럼 (분배) 이다. 이 문서는 그 두 파일이 왜 그렇게 생겼는지를 적은 근거본이며, 값이 바뀌면 CSV 를 고치고 이 문서를 다시 맞춘다.

스킬은 전부 패시브다. 배치만으로 작동하며 플레이어가 발동하는 액티브는 없다. 액티브 개입은 마법(SPEC 3-7)이 담당한다.

---

## 1. 왜 필요한가

스킬 분배 전까지 42종 유닛은 atk 숫자만 다른 같은 유닛이었다. 조합의 재미는 "무엇이 나오는가" 인데 결과물이 전부 같으면 STEP 3 게이트를 판정할 수 없다. 또 ROADMAP STEP 3 의 완료 조건인 "광역이나 관통이 없으면 밀집을 정리하지 못해 보스 제한시간을 못 맞춘다" 는 스킬 없이는 성립하지 않는다.

---

## 2. 분배 규칙

이 5개 규칙이 Data/units.csv 의 skillIds 를 결정한다. 규칙 1, 4, 5 는 테스트로 강제한다 (Tests/Synthesis.Core.Tests/CsvParserTests.cs).

| 번호 | 규칙 |
|---|---|
| 규칙 1 | 스킬 수는 등급-1 이다. 1성 0개, 2성 1개, 3성 2개, 4성 3개, 5성 4개 |
| 규칙 2 | 재료의 효과군을 우선 계승한다. 강도 단계는 자기 등급에 맞춰 올린다 |
| 규칙 3 | 유닛 정체성에 따라 계보에 없는 효과를 최대 1개까지 새로 도입할 수 있다 |
| 규칙 4 | 계열마다 그 계열의 주축 효과를 갖지 않는 유닛이 최소 1종 있어야 한다 |
| 규칙 5 | 5성 4종은 딜 배수, 다수 처리, 오라를 모두 갖고 단일 대상 기대 DPS 편차가 5% 이내다 |

**1성이 스킬 0개인 이유.** 조합해야 스킬이 생긴다. 1성 6종의 차이는 사거리와 공속으로 이미 존재하고, 첫 조합에서 스킬이 붙는 순간이 뽑기와 합성의 첫 보상 체감이 된다.

**규칙 4 가 핵심이다.** 계열이 유일한 분류 축이지만(BALANCE 1장), 그렇다고 같은 계열 유닛이 전부 같은 역할이면 조합 목표가 하나로 수렴한다. 계열은 성격이지 역할 고정이 아니다.

## 3. 중첩 규칙

**스택 키는 스킬 id 다.** 같은 스킬은 필드에 몇 기가 깔려 있어도 1회만 적용된다. 효과가 같아도 스킬 id 가 다르면 각각 더해진다.

| 상황 | 결과 |
|---|---|
| 프리스트 4기 (전부 WARCRY1) | 공격력 +15%. 같은 스킬이라 1회 |
| 프리스트 + 크루세이더 (WARCRY1 + WARCRY2) | 공격력 +40%. 스킬이 달라 둘 다 |
| 블랙스미스 + 세이지 (둘 다 SUNDER1) | 방어력 -4. 같은 스킬이라 1회 |
| 한 유닛이 MULTI2 와 MULTI3 를 동시 보유 | 추가 대상 1 + 2 = 3. 스킬이 달라 둘 다 |

**같은 유닛을 여러 기 쌓는 것으로는 아무것도 강해지지 않는다.** 조합해서 다른 스킬을 확보하는 것만이 유일한 강화 수단이다. 창고가 없어 재료용 하위 유닛이 필드에 남는 지금 구조에서 특히 중요하다. 이 규칙이 없으면 프리스트만 계속 쌓는 것이 최적해가 되어 조합할 이유가 사라진다.

합산은 전부 덧셈이다. 최대값을 취하거나 덮어쓰는 효과는 없다. 대신 상한을 둔다.

| 상한 | 값 | 이유 |
|---|---|---|
| 방어력 하한 | 0 | 방깎이 절대값이라 음수 방어력이 나오면 피해가 증폭된다 |
| 이동 속도 하한 | 기본 속도의 30% | 감속을 모으는 것만으로 몬스터가 사실상 정지하면 루프 디펜스가 성립하지 않는다 |

두 상한은 Core 의 ArmorFormula 와 CombatRules 에 한 벌로 있고 전투와 UI 가 같은 것을 쓴다.

### 3-1. 지속 피해는 장판이다

**도트를 몬스터에 붙는 디버프로 두지 않는다.** 유닛 주위 반경에 상시 깔리는 장판(DAMAGEZONE)이고, 몬스터는 그 안을 지나는 동안만 피해를 받는다.

디버프 방식이면 "누가 마지막에 때렸는가"가 세기를 정한다. 상급정령(약한 도트)이 정령왕(강한 도트)이 물린 몬스터를 때리면 효과가 약해지는 식이다. 조합해서 강해진다는 전제와 어긋난다. 장판은 위치에만 의존하므로 그런 순서 문제가 없고, 정령 계열이 루프 경로 어디를 덮을지가 배치 결정이 된다.

장판 피해도 방어력 감소 공식을 그대로 탄다. 방깎 유닛과 함께 두면 장판이 더 아프다.

## 4. 계열 주축과 이탈

| 계열 | 주축 효과 | 주축을 갖지 않는 유닛 |
|---|---|---|
| WAR 전사 | BONUSDAMAGE (고피해) | 성기사, 마법검사, 룬나이트 |
| ARC 궁수 | PIERCE (관통) | 레인저, 헌터 |
| MAG 법사 | AREADAMAGE (광역) | 주술사, 네크로맨서, 세이지 |
| PRI 사제 | ALLYBUFF (아군 강화) | 드루이드 |
| THI 도적 | CRIT (치명타) | 슬레이어 |
| SPI 정령 | DAMAGEZONE / SLOW (장판, 상태이상) | 블랙스미스 |

의도적 일탈 2건은 규칙 3 을 근거로 한다.

- **슬레이어**는 도적인데 치명타가 없고 HEAVY2 확정 고피해를 쓴다. 닌자(치명타 + 다중타격)와 성향을 갈라 놓기 위해서다.
- **블랙스미스**는 정령인데 장판도 감속도 없이 SUNDER1 방깎과 HASTE1 공속 오라를 쓴다. 정령왕을 거쳐 데미갓까지 이어지는 방깎 계보의 출발점이며, 보스 1(고방어) 대응 수단을 정령 계열에 심는다.

## 6. 5성 어태커 균형 (규칙 5)

5성 4종은 전부 기본 공격력 360, 공속 1.0 이라 기본 DPS 가 360 으로 같다. 여기에 스킬을 얹은 뒤에도 단일 대상 기대 DPS 가 비슷해야 한다. 어느 5성을 목표로 잡든 "이건 어태커가 아니라 서포터네" 가 되면 안 되기 때문이다.

오라형 아군 버프는 반경 안에 자기 자신도 들어가므로 자기 자신에게도 걸린다. 아래 계산은 그것을 반영한다.

| 5성 | 딜 배수 | 자기 강화 | 단일 대상 기대 DPS |
|---|---|---|---|
| 검성 라그나로크 | HEAVY3 x1.67 | WARCRY2 공격력 +25% | 360 x 1.67 x 1.25 = 750 |
| 그랜드마스터 | HEAVY4 x2.05 | 없음 | 360 x 2.05 = 738 |
| 유니온 센티넬 | CRIT4 x1.60 | HASTE2 공속 +30% | 360 x 1.60 x 1.30 = 749 |
| 데미갓 | HEAVY2 x1.50 | WARCRY3 공격력 +35% | 360 x 1.50 x 1.35 = 729 |

최대 750, 최소 729 로 편차 2.9% 다. 규칙 5 의 5% 이내를 만족한다.

그랜드마스터만 아군 버프가 없어 자기 강화가 없다. 그래서 딜 배수 하나를 다른 셋보다 높게 잡아 균형을 맞췄다. 대신 POISON4 장판을 들고 있어 반경 3 안에 머무는 적에게는 계산 밖의 추가 피해가 들어간다. 장판은 위치에 걸리는 효과라 단일 대상 기대 DPS 에 넣지 않는다.

단일이 같은 대신 밀집 처리량은 일부러 갈라 놓았다. 반경 안에 8기가 있을 때를 기준으로 보면 이렇다.

| 5성 | 다수 처리 수단 | 밀집 8기 처리량 |
|---|---|---|
| 그랜드마스터 | AREA4 반경2.5 에 90% | 약 4,860 |
| 검성 라그나로크 | AREA3 반경2.0 에 60% | 약 3,900 |
| 유니온 센티넬 | PIERCE3 3체 관통 | 약 2,250 |
| 데미갓 | MULTI3 3명 동시 | 약 2,190 |

광역은 밀도에 비례해 무한히 커지고 관통과 다중타격은 3체에서 멈춘다. 그래서 소수 정예나 보스 단독 국면에서는 넷이 대등하고, 밀집이 쌓이면 그랜드마스터와 검성이 해법이 된다. ROADMAP STEP 3 의 완료 조건이 여기서 성립한다.

보스 대응도 갈라 놓았다. 그랜드마스터와 데미갓은 SUNDER2 로 방어력 8 을 깎아 보스 1(고방어)에 강하고, 검성은 CHILL2 감속, 센티넬은 HASTE2 와 SIGHT2 로 주변 아군의 처리량을 올린다.

## 7. 확정되지 않은 것

- **모든 수치가 TEMP 다.** 5성 4종의 상대 균형만 맞춰 두었을 뿐, 절대값은 시뮬레이터로 확정한다 (STEP 7).
- **등급 간 DPS 비율이 INV-09 를 넘는다.** atk 격자가 이미 등급당 2.25배에서 2.8배인데(BALANCE 17 의 INV-09 상한은 2.6배) 여기에 스킬 배수가 곱해진다. atk 격자 자체가 TEMP 이므로 스킬 배수를 포함해 격자를 다시 잡아야 한다. 스킬 분배가 아니라 수치 확정 단계의 일이다.
- **장판 반경과 dps 균형이 미확정이다.** 장판은 유닛 위치에만 의존하므로 루프 경로를 얼마나 덮느냐가 실효 피해를 정한다. 맵 형태마다 달라지는 값이라 시뮬로 확인해야 한다.
- **장판을 유닛 중심으로 뒀다.** 명중 지점에 깔리고 시간이 지나면 사라지는 방식도 가능한데, 그러면 장판 개체의 수명 관리가 필요하고 "스킬은 전부 패시브" 규칙에서 벗어난다. 지금은 다른 오라(감속, 방깎)와 같은 취급으로 통일했다.
- **관통(PIERCE)과 다중타격(MULTITARGET)의 구현이 사실상 같다.** 둘 다 가까운 대상 여러 명에게 같은 피해를 준다. 관통을 직선 판정으로 분리할지는 미정이다.
