배치 위치: Docs/UNIT_RECIPES.md

원본은 Data/units.csv 와 Data/recipes.csv 다. 이 문서는 그 두 파일을 읽기 쉽게 정리한 참조본이며, 값이 바뀌면 CSV 를 고치고 이 문서를 다시 맞춘다.

---

## 1. 조합 UI 방식 (기획 메모)

유닛을 클릭하면, 그 유닛을 재료로 하는 조합식 목록을 보여주고 그중 하나를 선택해 조합한다.

- 클릭한 유닛이 조합의 기준(메인 재료)이 된다
- 그 유닛이 재료로 들어가는 조합식만 추려서 보여준다 (아래 4장 역참조 색인이 그 데이터다)
- 선택한 조합식의 나머지 재료가 인벤토리/필드 유닛으로 채워지면 조합이 성립한다

즉 UI 는 3장(정방향 조합식)이 아니라 4장(유닛별 역참조)을 근거로 목록을 만든다.

---

## 2. 조합 규칙 요약

- 조합식은 고정이다. 같은 재료는 항상 같은 결과를 낸다 (SPEC 3-3)
- 재료 개수는 등급별로 정해져 있다 (BALANCE 4~7장)

| 결과 등급 | 재료 구성 |
|---|---|
| 2성 | 1성 2기 |
| 3성 | 2성 2기 + 1성 1기 |
| 4성 | 3성 2기 + 2성 1기 |
| 5성 | 4성 2기 + 3성 1기 + 2성 1기 |

- 1성은 뽑기로만 얻는다 (6종, 계열당 1종)
- 선택권으로 상점에서 원하는 1성을 사서 부족한 1성 재료를 확보한다 (SPEC 2-2)
- 5성 1기는 1성 31기 상당의 재료가 든다 (2성=1성2, 3성=1성5, 4성=1성12, 5성=1성31)
