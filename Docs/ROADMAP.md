# ROADMAP.md

SYNTHESIS (가칭) - 개발 로드맵

배치 위치: Docs/ROADMAP.md / 버전 0.3

버전 0.3 변경: 공세 STEP 삭제, 루프 맵 생성기를 STEP 1로 편입, 전체 12단계에서 11단계로. 총 기간 53주에서 47주로 단축

---

## 0. 원칙

- STEP을 건너뛰지 않는다
- DoD를 만족하지 않으면 다음으로 넘어가지 않는다
- 게이트가 걸린 STEP은 통과 판정 없이 진행하지 않는다
- **STEP 8 이전에는 아트 비용을 한 푼도 쓰지 않는다**

전체 예상 기간 약 47주.

---

## STEP 1. 기반 도구 (4주)

### 목표

데이터 경로, 검증 도구, 그리고 맵 생성기를 먼저 만든다.

### 작업

- Shared/Synthesis.Core. UnityEngine 참조 없음을 CI로 강제
- Core/Fixed: long 기반 고정소수점 (스케일 1000)
- Core/Random: xorshift 계열 시드 주입 PRNG
- Core/Data: 데이터 모델과 CSV 파서
- **Core/Map: 루프 맵 생성기와 검증기 (MAP_SPEC.md)**
- Data/*.csv 초기 파일. BALANCE_SPEC.md 3장, 4장, 7장 표를 옮긴다. 전투 수치는 TEMP 표시
- Unity Editor 임포터: CSV to ScriptableObject
- Tools/Linter: INV-01 부터 INV-15, MAP-01 부터 MAP-07
- 결정성 테스트, 파서 일치 테스트, **맵 생성 재현성 테스트**

### DoD

- 린터가 CLI에서 돌고 전부 통과한다
- 같은 시드로 같은 맵이 나온다
- 1000개 맵을 생성했을 때 제약 위반과 폴백 발생률이 5% 미만이다
- Unity 없이 dotnet test로 Core 테스트가 돈다

---

## STEP 2. 뼈대 (4주)

### 목표

프리미티브로 루프 하나가 돌아간다.

### 작업

- Core/Simulation: 고정 20틱 루프 (스폰/순회/배치/코스트만. 전투는 Unity 실시간)
- 루프 순회 이동 (웨이포인트 인덱스 + 진행도, 마지막에서 0으로 회귀)
- 스폰 지점에서 유입
- 유닛 배치, 회수, 재배치, 코스트 회복
- 사거리 판정, 자동 공격, 역할별 공격 처리 (단일 / 라인 / 관통 / 지속) - Unity 실시간(CombatController)
- 웨이브 제한시간 카운터와 진행/패배 판정 (보스 웨이브 미처치 시 패배, SPEC 2-4)
- Unity 최소 View: 캡슐과 큐브, 고정 쿼터뷰 카메라
- 입력 추상화 (PointerEvent)

### DoD

- 프리미티브 상태로 여러 웨이브를 버틸 수 있다
- 보스 웨이브를 제한시간 내에 처리하지 못하면 패배한다 (필드 누적 상한 아님)
- 같은 시드로 두 번 돌려 Core 시뮬(스폰/순회/배치) 결과 해시가 일치한다 (전투는 실시간이라 결정성 대상 아님)
- 동시 60기 표시 상태에서 중저사양 실기 30fps를 유지한다

## STEP 3. 뽑기와 합성 (5주) [게이트]

### 목표

**이 프로젝트가 재미있는지 판정한다.**

덱 시스템은 없다(1성 6종뿐이라 선택이 무의미해 폐기, SPEC 2-3). 랜덤성 통제는 선택권이 담당한다.

### 작업

- 뽑기(웨이브마다 1성 1기 균등 지급, 보장 규칙 없음. 랜덤성 통제는 선택권이 담당)
- 등급 격자와 합성 판정
- 합성 UI. 보유 목록, 합성 가능 표시, 결과 미리보기
- 선택권(석상/보스 보상 + 상점). 석상 파괴와 보스 드랍으로 선택권 획득, 상점에서 원하는 1성 구매(SPEC 2-2)
- 도감

### DoD

- 뽑기와 합성만으로 런의 진행이 실제로 달라진다
- 히든 6종까지 도달 가능하다
- 라인 계열(광역/관통)이 없으면 밀집을 정리하지 못해 보스 제한시간을 못 맞춘다

### 게이트 판정

**프리미티브 상태로 3판 연속 하고 싶은가.**

통과하지 못하면 프로젝트를 재검토한다. 히어로로 이 판정을 미루지 않는다.

## STEP 4. 히어로 (4주)

### 목표

차별화 축을 붙인다. 합성이 히어로를 키우고, 히어로가 배치 퍼즐의 중심이 된다.

### 작업

- 히어로 5명. 필드 상주, 코스트 0, 자동 전투
- **오라 시스템. 반경 내 아군 버프 5종 (공격력 / 사거리 / 공속 / 관통 / 합성 코스트)**
- 합성 시 경험치 획득. 적 처치로는 획득하지 않음
- 레벨업과 스킬 카드 3택 1
- 스킬 카드 풀 80장. 초기에는 효과 12종 정도로 시작해 확장
- 진화쌍 15개
- 라인딜 계열 카드 (밀집 정리 수단)

### DoD

- 합성할 때 유닛과 히어로가 동시에 강해지는 것이 체감된다
- **히어로 위치를 바꾸면 전체 처리량이 눈에 띄게 달라진다**
- 히어로 5명의 최적 배치 성향이 서로 다르다

### 게이트 판정

**히어로 오라 때문에 배치를 고민하게 되는가.**

고민이 생기지 않으면 오라 수치가 약한 것이거나 오라 개념 자체가 실패한 것이다. 전자면 수치를 올리고, 후자면 차별화 축을 다시 찾아야 한다.

## STEP 5. 웨이브와 보스 (3주)

### 작업

- 웨이브 스케일링 곡선
- 보스 4기: 강철 성채(10), 창공의 눈(20), 잠든 왕(30), 파멸의 군주(40)
- 보스 소환 처리
- 승급 1부터 5와 뮤테이터
- 승리와 패배 처리, 결과 화면

### DoD

- 관통도 방깎도 없으면 보스 1에서 막힌다
- 라인딜이 없으면 보스 2 소환 밀집을 못 버텨 제한시간을 못 맞춘다
- 승급 3의 보스 제한시간 20% 감소가 체감된다

## STEP 6. 로그라이트 (3주)

### 작업

- 유물 80-100종. 5개 계열
- 위기계 유물 (밀집 정리)
- 메타 해금: 도감, 히어로 (덱 슬롯/편성은 덱 시스템 폐기로 제외)
- 무한 모드와 로컬 리더보드
- 런 진행 저장과 복구

### DoD

- 40웨이브를 완주할 수 있다
- 무한 모드가 해금되고 도달 웨이브가 기록된다

## STEP 7. 검증 (3주)

### 작업

- Sim/Synthesis.Sim 콘솔 프로젝트 (SIM_SPEC.md)
- 정책 구현: 합성 2종, 카드 선택 2종, 배치 2종 (덱 정책은 덱 시스템 폐기로 제외)
- 리포트 출력과 자동 판정
- SIM-01 부터 SIM-11 측정
- 위반 항목은 **구조가 아니라 수치를 조정**한다
- Unity 빌드와 Sim 콘솔의 동일 시드 결과 대조

### DoD

- SIM-01 부터 SIM-11 전부 통과
- 특히 SIM-10(맵 난이도 분산)과 SIM-11(맵별 최적 배치 차이) 통과
- CI에서 커밋마다 100런 결정성 검증이 돈다

### 주의

SIM-11이 실패하면 랜덤 맵 생성이 장식이라는 뜻이다. 생성 파라미터를 다시 잡거나, 최악의 경우 맵 랜덤화를 포기하고 고정 맵 몇 개로 되돌린다.
